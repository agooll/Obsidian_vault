# 02. static 静态成员通过类名访问

## 题目

关于类中的静态成员（`static`），以下哪项描述是正确的？

- A. 静态方法内部可以使用 `this` 关键字访问实例属性
- B. 静态成员需要通过类的实例（对象）来访问
- C. 静态成员在每个对象被创建时都会在内存中复制一份
- D. 静态成员可以直接通过类名进行访问，无需创建对象

## 正确答案

- `D. 静态成员可以直接通过类名进行访问，无需创建对象`

## 一句话理解

`static` 修饰的成员属于类，不属于某个具体对象，所以用 `类名.成员名` 访问。

## 对比例子

```TypeScript
class Person {
  name: string = 'Tom'               // 普通成员，属于对象
  static school: string = 'HMU'      // 静态成员，属于类

  static sayHi(): void {
    console.log('hi')
  }
}

let p = new Person()

console.log(p.name)
console.log(Person.school)
Person.sayHi()
```

这里的访问方式要分清：

1. `p.name`：对象访问普通成员
2. `Person.school`：类名访问静态成员
3. `Person.sayHi()`：类名访问静态方法

## 执行链路

可以按这个逻辑理解：

1. 定义 `Person` 类
2. `school` 和 `sayHi()` 直接挂在类上
3. 它们不是某个对象私有的
4. 所以不需要 `new Person()` 也能通过类名访问

## 错误选项为什么错

- A 错：静态方法不依附某个具体实例，不能把自己当成某个对象去访问实例属性
- B 错：静态成员本来就不是给对象访问的，而是给类名访问的
- C 错：静态成员不会每创建一个对象就复制一份，通常只有一份，所有实例共享

- `static = 属于类`
- `非 static = 属于对象`
- 口诀：`类名访问 static，对象访问实例成员`
