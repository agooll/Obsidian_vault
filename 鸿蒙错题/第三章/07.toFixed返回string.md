# 07. toFixed 返回 string

## 题目

ArkTS 中的 `Number` 对象方法 `toFixed(n)` 的返回值类型是什么？

- A. `boolean`
- B. `string`
- C. `object`
- D. `number`

## 正确答案

- `B. string`

## 一句话理解

`toFixed()` 的作用不是继续返回“数字对象”，而是把数字格式化成一个带固定小数位的字符串。

## 最小例子

```ArkTS
let price: number = 12.3456
let text: string = price.toFixed(2)
```

这里：

1. `price` 原本是数字
2. `toFixed(2)` 表示保留两位小数
3. 得到的结果是 `'12.35'`
4. 这个结果是字符串，不是 number

## 每个选项为什么对或错

### A. boolean

这是错的。

错在哪里：

- `toFixed()` 不是做真假判断
- 它不是返回 `true / false`
- 它的任务是“格式化显示”

改成什么才对：

- 改成“返回格式化后的字符串”才对

### B. string

这是正确项。

为什么对：

- `toFixed(n)` 会把数字转换成定点表示法文本
- 方便直接展示在 UI 或拼接文本里

例如：

```ArkTS
let s: string = (123.456).toFixed(1)   // '123.5'
```

### C. object

这是错的。

错在哪里：

- 返回结果不是一个对象实例
- 而是基本类型里的字符串值

为什么会误选：

- 因为它是 `Number` 相关方法
- 但“从 Number 上调用方法”不等于“返回 object”

改成什么才对：

- 改成“返回 string 类型的结果”才对

### D. number

这是错的。

错在哪里：

- 很多人看到“处理的是数字”，就以为返回还是数字
- 但 `toFixed()` 的重点是“格式化”
- 一旦涉及保留几位小数并按文本形式表达，返回值就是字符串

为什么会误选：

- 它看起来像是在做数值运算
- 实际上它更接近“把数字转成特定格式的文本”

改成什么才对：

- 改成“返回格式化后的字符串”才对
