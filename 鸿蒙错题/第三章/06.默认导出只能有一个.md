# 06. 默认导出只能有一个

## 题目

关于模块化的导出与导入，下列哪项描述是错误的？

- A. 一个文件中可以有多个默认导出（Default Export）
- B. 导入命名导出时通常需要使用大括号 `{}`
- C. 一个文件中可以有多个命名导出（Named Export）
- D. 使用 `export default` 可以进行默认导出

## 正确答案

- `A. 一个文件中可以有多个默认导出（Default Export）`

## 一句话理解

一个模块文件里：

- 默认导出最多只能有一个
- 命名导出可以有多个

## 最小例子

正确写法：

```TypeScript
export const a = 1
export const b = 2
export default function hello() {}
```

导入时：

```TypeScript
import hello, { a, b } from './utils'
```

这里可以这样看：

1. `hello` 对应默认导出
2. `{ a, b }` 对应命名导出
3. 命名导出可以有多个
4. 默认导出只能有一个

## 每个选项为什么对或错

### A. 一个文件中可以有多个默认导出（Default Export）

这是错误项。

错在哪里：

- 同一个模块文件里，语法上只允许一个默认导出
- 你不能在一个文件里连续写多个 `export default`

错误示例：

```TypeScript
export default class Person {}
export default function foo() {}
```

为什么会误选：

- 因为很多人把“默认导出”和“命名导出”混在一起
- 觉得既然能导出很多东西，那默认导出也能很多个

改成什么才对：

- 改成“一个文件中最多只能有一个默认导出”才对

### B. 导入命名导出时通常需要使用大括号 `{}`

这是正确项。

为什么对：

- 命名导出导入时，通常写法就是：

```TypeScript
import { foo, bar } from './utils'
```

- 大括号表示“我要从模块里取这些具体名字的成员”

### C. 一个文件中可以有多个命名导出（Named Export）

这是正确项。

为什么对：

- 你可以在同一个文件里导出多个变量、函数、类

例如：

```TypeScript
export const a = 1
export const b = 2
export class User {}
```

### D. 使用 `export default` 可以进行默认导出

这是正确项。

为什么对：

- `export default` 本来就是默认导出的语法

例如：

```TypeScript
export default Person
```

## 易混点

最容易混的是：

- 默认导出：只能一个
- 命名导出：可以多个

可以直接记口诀：

- `default`：一个文件最多一个
- `named`：一个文件可以很多个

- `export default`：默认导出
- `export const / class / function`：命名导出
- 口诀：`默认一个，命名多个`
