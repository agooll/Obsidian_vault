# 03. 类实现接口用 implements

## 题目

在 ArkTS 中，如果一个类想要实现某个接口，应该使用哪个关键字？

- A. `extends`
- B. `interface`
- C. `export`
- D. `implements`

## 正确答案

- `D. implements`

## 一句话理解

- `extends`：表示继承
- `implements`：表示实现接口

所以“类想实现接口”时，要用 `implements`。

## 对比例子

```TypeScript
interface DateInterface {
  now(): string
}

class MyDate implements DateInterface {
  now(): string {
    return 'now is now'
  }
}
```

这里的逻辑是：

1. 先用 `interface` 定义一个接口
2. 接口里规定“应该有什么方法”
3. 类如果想遵守这个接口规则，就写 `implements`
4. 然后在类里把接口要求的方法真正实现出来

## 为什么不是其他选项

- A 不是：`extends` 是“继承父类”或“接口继承接口”时用的，不是类实现接口
- B 不是：`interface` 是“定义接口”的关键字，不是“实现接口”的关键字
- C 不是：`export` 是模块导出关键字，和接口实现无关

## 易混点

最容易混的是 `extends` 和 `implements`：

- `extends`：更像“我继承你”
- `implements`：更像“我按你的规范来做”

可以直接记口诀：

- 类继承类：`extends`
- 类实现接口：`implements`

- `interface`：定义规则
- `implements`：遵守规则
- 口诀：`接口先定义，类再 implements`
