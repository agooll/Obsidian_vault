# 01. super 必须在 this 之前

## 题目

如果子类构造方法中使用了 `this` 关键字，那么关于 `super` 的调用顺序要求是？

- A. `super` 和 `this` 的顺序可以随意交换
- B. `super` 必须出现在 `this` 之前
- C. `this` 必须出现在 `super` 之前
- D. 构造方法中不允许同时出现 `super` 和 `this`

## 正确答案

- `B. super 必须出现在 this 之前`

## 一句话理解

子类对象在真正可用之前，必须先让父类那一部分完成初始化，所以要先 `super()`，后 `this`。

## 执行链路

```TypeScript
class Animal {
  name: string

  constructor(name: string) {
    this.name = name
  }
}

class Dog extends Animal {
  age: number

  constructor(name: string, age: number) {
    super(name)
    this.age = age
  }
}
```

可以按这个顺序理解：

1. 创建 `Dog` 对象
2. 先调用 `super(name)`
3. 先执行父类 `Animal` 的构造函数
4. 父类部分完成初始化，例如 `this.name = name`
5. 再回到子类构造函数
6. 最后执行 `this.age = age`

## 为什么不能先用 this

错误写法：

```TypeScript
class Dog extends Animal {
  age: number

  constructor(name: string, age: number) {
    this.age = age
    super(name)
  }
}
```

这里会报错，因为在 `super()` 之前，父类部分还没初始化完成，当前对象还不是一个完整可用的子类实例。

## 错误选项为什么错

- A 错：`super` 和 `this` 的顺序不能交换
- C 错：这和真实规则正好相反
- D 错：两者可以同时出现，但必须先 `super()` 再 `this`

- `super()`：先初始化父类部分
- `this`：再操作当前子类对象
- 口诀：`先 super，后 this`
