# 05. 自动装箱的典型例子

## 题目

关于 ArkTS 中的“自动装箱”现象，以下哪个例子体现了这一点？

- A. 通过 `JSON.parse()` 解析字符串
- B. 将一个数字赋值给变量，如 `let a = 10`
- C. 使用 `new Number(123)` 创建对象
- D. 在基本类型值上直接访问属性或调用方法，例如字符串的 `.length`

## 正确答案

- `D. 在基本类型值上直接访问属性或调用方法，例如字符串的 .length`

## 一句话理解

自动装箱就是：基本类型本来不是对象，但在需要对象能力时，运行时会临时把它包装成对应对象。

## ArkTS 语境下怎么理解

在这套笔记里，原知识点已经明确写到：

- 基本类型的值可以被自动装箱
- 因此它们可以在某些场景下表现出“像对象一样”的能力

例如：

```ArkTS
let value: Object = 123
let text: string = 'abc'
let len: number = text.length
```

这里可以这样看：

1. `123` 本来是基本类型
2. 但它可以赋给 `Object`
3. `text` 本来也是基本类型字符串
4. 却仍然可以访问 `.length`
5. 这类现象可以从“自动装箱”角度理解

## 每个选项为什么错

### A. 通过 `JSON.parse()` 解析字符串

错在哪里：

- 这是在调用 `JSON` 对象的静态方法
- 重点是“解析 JSON 字符串”
- 它和“基本类型临时变成对象”不是一回事

为什么会误选：

- 因为它也处理字符串
- 但“处理字符串”不等于“发生自动装箱”

改成什么才对：

- 如果要体现自动装箱，应该换成“基本类型直接访问属性/方法”的例子

### B. 将一个数字赋值给变量，如 `let a = 10`

错在哪里：

- 这只是最普通的赋值
- 没有体现“对象能力”
- 也没有出现属性访问或方法调用

为什么会误选：

- 有些人会把“数字被保存到变量里”误以为已经变成对象
- 但这里只是值绑定，没有体现装箱

改成什么才对：

- 至少要出现“把基本类型当成对象来用”的场景才更贴近自动装箱

### C. 使用 `new Number(123)` 创建对象

错在哪里：

- 这不是自动装箱
- 这是你手动显式创建了一个包装对象

为什么会误选：

- 因为它确实产生了“数字对象”
- 但题目问的是“自动装箱”，不是“手动装箱”

改成什么才对：

- 它应该被表述为“显式装箱”或“手动创建包装对象”

### D. 在基本类型值上直接访问属性或调用方法，例如字符串的 `.length`

这是正确项。

为什么对：

- 基本类型本来不是对象
- 但你却能直接访问它的属性或方法
- 这正体现了运行时临时提供对象能力的效果

## 易混点

最容易混的是：

- `new Number(123)`：显式装箱
- `'abc'.length`：自动装箱角度下的典型表现

所以要分清：

- “我自己手动 new 出来”不是自动
- “我没 new，但基本类型却能像对象一样用”才更符合自动装箱现象

## 复习提醒

- 自动装箱：运行时临时包装
- 显式装箱：自己手动 `new`
- 口诀：`没 new 还能像对象一样用，优先想到自动装箱`
