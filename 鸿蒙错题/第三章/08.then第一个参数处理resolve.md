# 08. then 第一个参数处理 resolve

## 题目

使用 Promise 对象的 `then()` 方法时，其第一个参数通常代表什么逻辑？

- A. 操作失败（`reject`）时的回调函数
- B. 操作成功（`resolve`）时的回调函数
- C. 用于重试当前异步任务的递归函数
- D. 无论成功或失败都会执行的清理函数

## 正确答案

- `B. 操作成功（resolve）时的回调函数`

## 一句话理解

`then()` 的第一个参数，专门用来接收 Promise 成功完成之后的结果。

## 最小例子

```ArkTS
let promise = Promise.resolve('成功')

promise.then(value => {
  console.log(value)
})
```

这里的执行链路是：

1. Promise 被 `resolve('成功')`
2. 表示异步任务成功完成
3. `then()` 的第一个参数被调用
4. `value` 拿到成功结果 `'成功'`

## 每个选项为什么对或错

### A. 操作失败（reject）时的回调函数

这是错的。

错在哪里：

- `reject` 对应的是失败分支
- 失败通常由 `catch()` 处理
- 或者由 `then()` 的第二个参数处理

为什么会误选：

- 因为很多人只记得 `then()` 和 Promise 绑定
- 但没分清成功分支和失败分支

改成什么才对：

- 改成“成功时的回调函数”才对

### B. 操作成功（resolve）时的回调函数

这是正确项。

为什么对：

- Promise 成功完成后
- `then()` 的第一个参数会收到成功结果
- 这是最常见的 Promise 成功处理入口

### C. 用于重试当前异步任务的递归函数

这是错的。

错在哪里：

- Promise 本身不自带“自动重试”机制
- `then()` 的第一个参数只是接收成功结果
- 重试逻辑要开发者自己额外写

改成什么才对：

- 如果想表达重试，应该写成“开发者自己封装重试逻辑”

### D. 无论成功或失败都会执行的清理函数

这是错的。

错在哪里：

- 这种“无论成功失败都执行”的逻辑，更接近 `finally()`
- 不是 `then()` 的第一个参数

为什么会误选：

- 因为三者都和 Promise 链式调用有关
- 容易把 `then`、`catch`、`finally` 的职责混在一起

改成什么才对：

- 改成“`finally()` 用于收尾清理”才对

## 复习提醒

- `then(第一个参数)`：处理成功
- `catch()`：处理失败
- `finally()`：统一收尾
- 口诀：`then收成功，catch收失败，finally做收尾`
