### ReAct Loop 全流程
1. LLM
   LLM 输出：
   Action: Search[深圳天气] 

2. Action parser
   从字符串里提取：
   tool_name = "Search"
   tool_input = "深圳天气" 
   
3. Registry
   registry.get_tool("Search") 

4. Execute/Executor
   search.execute("深圳天气") 

5. observation
   返回：
   "深圳今天多云..." 

6. self.history = history+observation
   把：
   Observation: 深圳今天多云...
   加进 history 
   
7. React Loop
   LLM 根据 Observation 决定下一步
