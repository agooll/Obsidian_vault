### ReAct Loop 全流程
1. LLM 输出：
   Action: Search[深圳天气] 
   

2. 从字符串里提取：
   tool_name = "Search"
   tool_input = "深圳天气" 
   Action search

3. registry.get_tool("Search") Registry

4. search.execute("深圳天气") execute

5. 返回：
   "深圳今天多云..." observation

6. 把：
   Observation: 深圳今天多云...
   加进 history 
   self.history = 

7. LLM 根据 Observation 决定下一步
