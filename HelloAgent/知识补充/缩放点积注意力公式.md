Transformer 机制中最核心的 **缩放点积注意力公式（Scaled Dot-Product Attention）**：

$$\text{Attention}(Q, K, V) = \text{softmax}\left(\frac{QK^T}{\sqrt{d_k}}\right)V$$

我们可以把这个公式拆解成一个非常直观的“搜索引擎/数据库查询”过程：

- **$Q$ (Query / 查询)**：你想查找的目标（比如你在搜索框输入的关键字）。
    
- **$K$ (Key / 键)**：数据库里每个条目的标签/索引（用来匹配你的关键字）。
    
- **$V$ (Value / 值)**：数据库里每个条目对应的真正内容。
    

## 公式四步拆解

这个公式看似复杂，其实就是做了 **4 个步骤**：

### 1. 计算关联分数：$QK^T$

- **做了什么**：将 $Q$ 和 $K$ 的转置相乘（点积）。
    
- **代表什么**：衡量每个 Query 和每一个 Key 之间的**相关度/相似度**。点积越大，说明两者关联度越高。
    
- **对应代码**：`scores = Q @ K.transpose(-2, -1)`。这里转置最后两维，让形状从 `[..., query_len, head_dim]` 和 `[..., key_len, head_dim]` 变成可相乘的形状，最终得到 `[..., query_len, key_len]` 的关联分数矩阵。
    

### 2. 缩放（Scaling）：$\div \sqrt{d_k}$

- **做了什么**：把上一步算出的分数除以 $\sqrt{d_k}$（$d_k$ 是向量维度 `head_dim`）。
    
- **为什么做**：当维度 $d_k$ 很大时，点积数值也会变得非常大，这会导致下一步的 Softmax 函数梯度变得极小（梯度消失），模型很难训练。除以 $\sqrt{d_k}$ 能把数值拉回到合理的平稳区间。
    

### 3. 概率化（Softmax）：$\text{softmax}(\dots)$

- **做了什么**：对关联分数在最后一个维度归一化。
    
- **代表什么**：把原始的分数转换成**概率分布（权重系数）**，所有权重的和等于 1。比如得出注意力分布：当前 token 有 70% 的注意力在“苹果”上，20% 在“手机”上，10% 在“发布会”上。
    

### 4. 加权求和：$\times V$

- **做了什么**：用上一步得到的“注意力权重”，去乘以真正的特征内容 $V$。
    
- **代表什么**：根据关联度大小提取信息，关联度高的 $V$ 占的比重大，关联度低的占的比重小。最终输出包含了上下文全局信息的新特征表示。
    

## 总结

一句话概括这个公式：**“用 $Q$ 和 $K$ 计算相似度确定权重，再用这个权重去提取 $V$ 中的核心信息。”**



**Scaled Dot-Product Attention** 中文叫：

> **缩放点积注意力**

它就是 Transformer 里最基础的一种注意力计算方式。你之前计算的 **QKTQK^TQKT**，正是它的核心步骤。

公式是：

Attention(Q,K,V)=Softmax(QKTdk)V\text{Attention}(Q,K,V) = \text{Softmax}\left( \frac{QK^T}{\sqrt{d_k}} \right)VAttention(Q,K,V)=Softmax(dk​​QKT​)V

---

### 1. 用 QKTQK^TQKT 计算关联分数

假设一句话有 3 个 Token，每个 Token 都会生成：

- QQQ：Query，表示“我正在找什么信息”
- KKK：Key，表示“我能提供什么信息”
- VVV：Value，表示“我实际携带的信息”

计算：

QKTQK^TQKT

就是让每个 Token 的 QQQ，分别和所有 Token 的 KKK 做点积。

例如：

QKT=[210131012]QK^T= \begin{bmatrix} 2 & 1 & 0\\ 1 & 3 & 1\\ 0 & 1 & 2 \end{bmatrix}QKT=​210​131​012​​

- 第 1 行：第 1 个 Token 对所有 Token 的关注分数
- 第 2 行：第 2 个 Token 对所有 Token 的关注分数
- 第 3 行：第 3 个 Token 对所有 Token 的关注分数

例如第一行：

[2,1,0][2,1,0][2,1,0]

表示第一个 Token：

- 对第一个 Token 的原始分数是 2
- 对第二个 Token 的原始分数是 1
- 对第三个 Token 的原始分数是 0

这里的分数还不是最终权重。

### 2. 除以 dk\sqrt{d_k}dk​​ 进行缩放

QKTdk\frac{QK^T}{\sqrt{d_k}}dk​​QKT​

这里的 dkd_kdk​ 是每个 QQQ、KKK 向量的维度。

dk=4d_k=4dk​=4

dk=4=2\sqrt{d_k}=\sqrt{4}=2dk​​=4​=2

原来的分数：

[2,1,0][2,1,0][2,1,0]

缩放后：

[1,0.5,0][1,0.5,0][1,0.5,0]

这就是名字中 **Scaled，缩放** 的来源。

#### 为什么要缩放？

当向量维度很大时，点积结果可能变得很大。

比如：

[20,10,5][20,10,5][20,10,5]

经过 Softmax 后，最大的值可能会接近 1，其他值接近 0，导致注意力过于极端，训练时梯度也容易变得很小。

除以：

dk\sqrt{d_k}dk​​

可以把数值控制在更合理的范围。

---

### 3. 使用 Softmax 转换为注意力权重

缩放后的分数：

[1,0.5,0][1,0.5,0][1,0.5,0]

经过 Softmax，可能得到：

[0.506,0.307,0.186][0.506,0.307,0.186][0.506,0.307,0.186]

它们满足：

0.506+0.307+0.186≈10.506+0.307+0.186\approx10.506+0.307+0.186≈1

这表示当前 Token：

- 50.6% 关注第一个 Token
- 30.7% 关注第二个 Token
- 18.6% 关注第三个 Token

Softmax 是对 **每一行单独计算** 的。

因此注意力矩阵中的每一行之和都等于 1。
