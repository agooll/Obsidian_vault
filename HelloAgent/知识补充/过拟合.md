**过拟合（Overfitting）** 是机器学习和深度学习中最常见的问题之一。简单来说，就是**模型在训练数据上表现极好，但在面对未见过的测试数据（新数据）时却表现很差**。

## 1. 直观比喻：死记硬背 vs 举一反三

> **死记硬背（过拟合）**： 假设你在备考，把刷过的 100 道练习题连同题目里的数字和标点符号都**死记硬背**了下来。在做这 100 道原题时你能拿 100 分，但考试时题目稍微改动了一个数字，你就完全不会做了。
> 
> **举一反三（理想状态 / 泛化能力）**： 掌握了解题的本质逻辑和规律，即使遇到从未见过的全新题目，也能准确推导并解答。
## 2. 过拟合的表现特征

在训练模型（比如训练神经网络）时，可以通过看训练集和验证集的 **Loss（损失）** 或 **Accuracy（准确率）** 曲线来判断是否发生了过拟合：

| **指标**    | **训练集（Training Set）**  | **验证集 / 测试集（Validation / Test Set）** |
| --------- | ---------------------- | ------------------------------------ |
| **正常状态**  | Loss 持续下降，准确率提升        | Loss 持续下降，准确率提升                      |
| **过拟合状态** | Loss 极低，准确率接近 **100%** | Loss 降到一定程度后**反而开始上升**（准确率卡住或下降）     |
### 3. 为什么会发生过拟合？

1. **模型太复杂（参数量过多）**：模型的表达能力远远超过了任务本身需要的复杂度（比如用多项式拟合一条直线的散点图）。模型不仅学到了真实的数据规律，还把数据里的**随机噪声**和**偶发特征**也当成规则记了下来。
    
2. **训练数据量太少 / 缺乏多样性**：如果样本很少，模型很容易找出一些“虚假的相关性”。
    
3. **训练轮次（Epochs）过多**：在训练集上反复迭代太多次，模型开始“钻牛角尖”。
    
4. **数据标签存在噪声**：数据集中有标注错误的数据，模型强行去拟合这些错误。
#### 4. 解决过拟合的常见手段

在实际工程中，解决过拟合主要从**数据**、**模型结构**和**训练过程**三方面入手：

##### ① 针对数据

- **增加数据量**：数据越多，模型越难记住所有细节，只能被迫去学习通用的宏观规律。
    
- **数据增强（Data Augmentation）**：在视觉中对图片进行旋转、裁剪、翻转、加噪声等，人为增加数据的丰富度。
    

##### ② 针对模型结构

- **降低模型复杂度**：减少神经网络的层数或每层的神经元数量。
    
- **加入 Dropout（随机失活）**：在训练过程中按一定概率随机将部分神经元的输出清零（例如之前代码里的 `nn.Dropout(0.1)`），打破神经元之间的强依赖，逼迫网络学习更健壮的特征。
    
- **正则化（Regularization，$L_1 / L_2$ 正则化）**：在损失函数中加入对模型权重大小的惩罚项（如 Weight Decay），防止某些权重变得过大，抑制模型的过度拟合能力。
    

##### ③ 针对训练过程

- **早停法（Early Stopping）**：在训练过程中时刻监控验证集的 Loss，一旦发现验证集的 Loss 连续几个 Epoch 不再下降甚至开始反弹，就提前终止训练。
