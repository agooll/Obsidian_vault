## 一、最终要做出的项目

项目暂定名：**EvidenceAgent——可信技术调研智能体**

### 1. 项目要解决的问题

用户输入一个技术问题并上传相关资料，Agent 自动完成：

1. 将开放问题拆解为多个可检索的子问题；
2. 检索本地文档，网页搜索作为可选加分项；
3. 对检索结果进行去重、排序和证据筛选；
4. 生成带来源引用的结构化调研报告；
5. 检查报告中的关键结论是否有证据支撑；
6. 记录运行轨迹、延迟、Token 消耗和失败原因；
7. 使用固定评测集衡量引用正确率、任务完成率、延迟和成本。

### 2. 推荐技术栈

- Python 3.10+
- PyTorch、Transformers
- FastAPI
- Streamlit
- Pydantic
- FAISS 或 Chroma
- BM25，可选增加 Reranker
- pytest
- Docker
- GitHub Actions

模型优先复用本地 Qwen；如果本地模型效果不足，再接入一个兼容 OpenAI API 格式的模型服务。密钥只放 `.env`，不得提交到 Git。

## 五、进度落后时的删减顺序

如果某周落后，不要通过熬夜同时保留所有功能。按照下面的优先级处理。

### P0：绝对不能删

1. 端到端可运行的 Agent；
2. RAG 和真实引用；
3. 固定评测集和 Benchmark；
4. 测试、README、架构图；
5. 简历、演示视频和投递。

### P1：尽量保留

1. Reflection；
2. 超时、重试、缓存；
3. FastAPI 和简单 UI；
4. Docker 和 CI。

### P2：时间不足可以后置

1. MCP；
2. 长期 Memory；
3. 网页搜索；
4. 复杂多智能体协作；
5. 精美 UI；
6. Agentic RL。

原则：**宁可删掉一个时髦功能，也不能删掉评测、文档和可运行演示。**
